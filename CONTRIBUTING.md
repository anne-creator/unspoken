# Contributing

Created and maintained by Anne. Please open an issue describing a bug or proposed change, then submit a focused pull request.

Install the development dependencies and run `python -m pytest -q`. Add behavior-focused tests when changing the simulator, routing, policy, APIs or scenario runner. Keep changes to model prompts accompanied by evaluation evidence. Live tests are opt-in and may incur inference charges.

Never commit credentials, private access configuration, model weights, runtime traces or account-specific resource inventories. Preserve vendored license files. UI changes should work with keyboard navigation and narrow screens, and clearly distinguish simulated data from real inference.
