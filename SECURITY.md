# Security

This project simulates a home. Do not connect it to physical locks, appliances or other safety-sensitive devices without a separate security and safety review.

Keep the application and model bound to loopback and use a TLS reverse proxy for hosting. Public demo controls share state and can trigger paid model calls. Configure access controls and usage limits appropriate to your deployment.

Please use GitHub's private vulnerability reporting feature when available to report security issues to Anne. Do not place credentials or private infrastructure details in a public issue. If private reporting is unavailable, open an issue requesting a private contact channel without disclosing the vulnerability details.
